# FarmClash

Браузерная многопользовательская игра в духе agar.io: ограниченный открытый мир,
PvP + PvE. Фармишь мобов, строишь фермы и шахты ради пассивного дохода, покупаешь
оружие, рейдишь чужие постройки и охотишься на боссов — при смерти теряются деньги
и предметы, так что каждая вылазка — риск.

- **Клиент**: TypeScript + PixiJS v8 (WebGL), Vite
- **Сервер**: Node.js 22 + `ws`, авторитарная симуляция 20 TPS, spatial hash grid,
  area-of-interest снапшоты
- **Данные**: SQLite (better-sqlite3) — телеметрия для настройки баланса
- **Баланс**: все игровые числа в [`balance/balance.json`](balance/balance.json),
  горячая перезагрузка без рестарта; дашборд аналитики на `/admin/stats`

## Быстрый старт (разработка)

```bash
npm install
npm run dev          # сервер на :3000 + Vite на :5173
```

Откройте http://localhost:5173 в двух вкладках — вы увидите друг друга.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер + клиент в dev-режиме |
| `npm run build` | сборка клиента в `client/dist` |
| `npm run start` | продакшен-сервер (отдаёт и клиент, если собран) |
| `npm run test` | юнит-тесты (grid, баланс-схема, раздел наград) |
| `npm run check` | проверка типов везде |
| `npm run bots -- --n 30` | нагрузочный тест ботами |

## Управление

WASD — движение · мышь — прицел · ЛКМ — атака · B — магазин · Q — еда ·
1–4 — оружие (слоты можно перетаскивать) · Esc/ПКМ — отмена · ⚙ — настройки.
Зум фиксированный — все игроки видят одинаковую область (честный PvP).

**Мобильные устройства**: левый джойстик — движение; большая кнопка ⚔ —
тап = удар с автоприцелом по ближайшему врагу, зажать и потянуть — ручной
прицел и непрерывная стрельба; кнопки 🍖 (еда) и 🛒 (магазин).

## Мир — 5 биомов

```
┌────────┬──────────────────┬────────┐
│ Тёмный │      Снега       │Кристал.│
│  лес   ├──────────────────┤пустоши │
│        │     Равнина      │        │
│ (мист.)├──────────────────┤ (мист.)│
│        │     Пустыня      │        │
└────────┴──────────────────┴────────┘
```

У каждого биома свои мобы (равнина: слайм/волк · снега: ледяной слайм/йети ·
пустыня: скорпион/песчаный голем · мистические: тени, тренты, виспы, кристальные
големы — сильнее и дороже). Боссы: **Чемпион** в центральных биомах, **Владыка
Теней** и **Кристальная Королева** — усиленные боссы мистических краёв, привязаны
к своим биомам.

## Механики

- **Аккаунты**: регистрация по имени + паролю — золото, оружие и коллекция
  шляп сохраняются между сеансами и переносятся между серверами. Можно играть
  гостем (без сохранения). Зарегистрированное имя защищено от гостей.
- **Динамические игровые миры**: держится минимум `world.servers` всегда-онлайн
  миров, а под нагрузкой новые создаются по мере заполнения (до `world.maxServers`)
  и гасятся, когда пустеют — места «не кончаются» в пределах машины. Вход
  автоматически на первый свободный (игроки уплотняются в младшие миры); ручной
  выбор — в настройках (⚙), лимит `world.maxPlayers` (40) на мир.
- **Шляпы** (коллекция, не теряются при смерти; надета одна): обычные падают
  с мобов (~1%), редкие — с боссов (25% участникам награды), эпические и
  легендарные — только из лутбокса за 500 золота (2% легендарная, 8% эпическая,
  30% золото, 60% пусто). Дубликат превращается в золото по грейду
  (100/500/1500/5000). Эффекты: скорость, HP, урон, лечение едой, доход
  построек, реген, магнит монет, шанс еды с мобов, награда за мобов,
  быстрое возрождение, сохранение денег при смерти, урон боссам (только PvE —
  прямых PvP-бафов урона у новых шляп нет).
- **Уровни** (1→10, по 100 золота за уровень — без прогрессии, всего 900 за
  максимум): каждый уровень даёт +10 HP и +3% урона. На максимуме — 190 HP и
  ×1.27 урона: комфортно в PvE против обычных мобов, но босса в одиночку не
  одолеть — **бонус урона на боссов не действует**, они остаются групповой
  целью. Уровни — характеристика текущей жизни: **теряются при смерти** (как
  оружие и золото), поэтому PvP честный и возможны камбэки.
- **Нет безопасной зоны**: PvP везде. После возрождения — 3 секунды
  неуязвимости (сбрасывается твоей же атакой). Магазин работает из любой
  точки мира.
- **Смерть**: теряешь 50% денег (выпадают монетами) и ВСЁ купленное оружие
  и еду.
- **Еда** — главный скилловый фактор: выпадает из мобов и продаётся в магазине.
  Q восстанавливает +30 HP с перезарядкой 2с. Кто вовремя жмёт еду и накопил
  запас — тот выигрывает размен в PvP.
- **Оружие** (11 видов, продаётся обратно за 50% цены). Классика: меч / копьё /
  молот (AoE + отброс) / лук / арбалет. Со спецспособностями: **кинжалы**
  (удар в спину ×2.5), **коса** (бьёт вокруг на 360°), **ядовитый клинок**
  (яд 6/с на 4с — течёт даже после отхода), **клинок вампира** (лечит 20%
  нанесённого урона), **тройной лук** (3 стрелы веером), **ледяной посох**
  (замедляет цель на 35% на 1.5с). Способности сбалансированы низким прямым
  уроном/скоростью — сила в правильном применении, а не в цифрах.
- **Мобы** по биомам, невысокая плотность; мистические — самые опасные и
  прибыльные. Мобы не покидают свой биом.
- **Боссы** (3 вида) по таймерам: телеграфируемые атаки, награда делится по
  нанесённому урону; мистические боссы вдвое жирнее и щедрее.
- **Престиж** — слив избытка золота в статус: уровни с растущей ценой (×1.5 за уровень). Награды чисто косметические: цвет и значок имени (✦N), светящаяся аура, тир (Бронза→Легенда) — видно всем и в ленте убийств. **На бой не влияет.**
- **Постройки** (до 5): ферма и шахта дают доход, турель защищает. Живут только
  пока владелец онлайн — при выходе исчезают. Чужие постройки можно разрушать —
  рейдер получает 50% их стоимости.

## Структура

```
balance/balance.json   — все игровые числа (hot-reload)
shared/src/            — протокол и типы, общие для клиента и сервера
server/src/game/       — мир, бой, мобы, босс, постройки, экономика
server/src/db/         — SQLite + телеметрия (kills/damage/income/…)
server/src/admin/      — /admin/stats — дашборд баланса
client/src/            — PixiJS-рендер, интерполяция, предсказание, UI
```
