# Farmilka

Браузерная многопользовательская игра в духе agar.io: ограниченный открытый мир,
PvP + PvE. Фармишь мобов, строишь фермы и шахты ради пассивного дохода, покупаешь
оружие, рейдишь чужие постройки и охотишься на босса — деньги теряются при смерти,
так что каждый выход из безопасной зоны — риск.

- **Клиент**: TypeScript + PixiJS v8 (WebGL), Vite
- **Сервер**: Node.js 22 + `ws`, авторитарная симуляция 20 TPS, spatial hash grid,
  area-of-interest снапшоты
- **Данные**: SQLite (better-sqlite3) — телеметрия для настройки баланса
- **Баланс**: все игровые числа в [`balance/balance.json`](balance/balance.json),
  горячая перезагрузка без рестарта; дашборд аналитики на `/admin/stats`

## Быстрый старт (разработка)

```bash
npm install
npm run dev          # сервер на :3000 + Vite на :5173
```

Откройте http://localhost:5173 в двух вкладках — вы увидите друг друга.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер + клиент в dev-режиме |
| `npm run build` | сборка клиента в `client/dist` |
| `npm run start` | продакшен-сервер (отдаёт и клиент, если собран) |
| `npm run test` | юнит-тесты (grid, баланс-схема, раздел наград) |
| `npm run check` | проверка типов везде |
| `npm run bots -- --n 30` | нагрузочный тест ботами |

## Управление

WASD — движение · мышь — прицел · ЛКМ — атака · B — магазин · Q — еда ·
1–4 — оружие (слоты можно перетаскивать) · Esc/ПКМ — отмена · ⚙ — настройки.
Зум фиксированный — все игроки видят одинаковую область (честный PvP).

**Мобильные устройства**: левый виртуальный джойстик — движение, правый —
прицел + стрельба, кнопки 🍖 (еда) и 🛒 (магазин).

## Механики

- **Аккаунты**: регистрация по имени + паролю — золото и купленное оружие
  сохраняются между сеансами. Можно играть гостем (без сохранения).
  Зарегистрированное имя защищено от гостей.
- **Безопасная зона** в центре: нет PvP, там магазин и респавн.
- **Смерть**: теряешь 50% денег (выпадают монетами) и ВСЁ купленное оружие
  и еду — каждый выход из зоны это риск.
- **Еда** — главный скилловый фактор: выпадает из мобов и продаётся в магазине.
  Q восстанавливает +30 HP с перезарядкой 2с. Кто вовремя жмёт еду и накопил
  запас — тот выигрывает размен в PvP.
- **Оружие**: меч / копьё / молот (AoE + отброс) / лук / арбалет — покупается
  в зоне, продаётся обратно за 50%.
- **Мобы** по кольцам сложности: слаймы → волки → големы (награда растёт).
- **Босс** каждые 15 минут: телеграфируемые атаки, награда делится по нанесённому урону.
- **Постройки** (до 5): ферма и шахта дают доход, турель защищает. Живут только
  пока владелец онлайн — при выходе исчезают. Чужие постройки можно разрушать —
  рейдер получает 50% их стоимости.

## Структура

```
balance/balance.json   — все игровые числа (hot-reload)
shared/src/            — протокол и типы, общие для клиента и сервера
server/src/game/       — мир, бой, мобы, босс, постройки, экономика
server/src/db/         — SQLite + телеметрия (kills/damage/income/…)
server/src/admin/      — /admin/stats — дашборд баланса
client/src/            — PixiJS-рендер, интерполяция, предсказание, UI
```
