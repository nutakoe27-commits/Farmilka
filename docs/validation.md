# Проверки и статус моделей

Дата обновления: 30 октября 2026, Europe/Moscow. Рабочая ветка `main`.

## CPU-среда разработки

- Frozen lockfile согласован с pyproject; версии всех прежних зависимостей сохранены.
- Добавлены только bitsandbytes, PEFT, SentencePiece и protobuf в optional extra.
- **30 тестов pytest прошли**: основной протокол, очереди и файлы, новый тип воркера,
  отдельные кэши моделей, закрепление ревизий, восстановление без сети,
  проверка места, безопасный запрос токена и перенос hooks между пайплайнами.
- Одно предупреждение Starlette о будущей замене HTTPX в TestClient.
- 10 языков интерфейса, 37 строк на язык; переводы и синтаксис JavaScript проверены.
- Compose overlay для LoRA проходит `config --quiet`.
- Проверка CUDA/NF4/PEFT на настоящей видеокарте в этой CPU-среде не выполнялась.

## Подтверждено на GPU-сервере пользователя до переезда

Это отдельная арендованная QuData VM; GPU не является частью облачной CPU-среды Codex.
Данные получены из команд и изображений, которые пользователь прислал в чат:

- RTX 3090 Ti, 23.5 GiB VRAM; драйвер 580.178.04.
- PyTorch 2.10.0+cu128; CUDA bfloat16 matrix operation: PASS в GPU-контейнере.
- Klein 4B скачан и загружен; воркер сообщил `Engine ready: flux`.
- Настоящий text-to-image 512×512: `PASS engine=flux`, полный запрос 32.5 секунды.
  Пользователь открыл результат: красный чайник у окна на деревянном столе.
- Фото + инструкция проверены полученным изображением: чайник стал синим,
  основная композиция сохранилась. Время этого запроса не зафиксировано.
- Веб-интерфейс открыт на Mac через личный SSH-туннель; заполнение ключа и
  отдельный запуск генерации из браузера ещё не подтверждены.
- Первичный экспорт GPU-образа был длительным. Экспорт без сжатия завершился:
  445.3 секунды экспорт слоёв, 73.7 секунды unpack, всего этапа 519.3 секунды.
  Это наблюдение не доказывает единственную причину предыдущей задержки.

## Новый режим Heartsync: пока не проверен на реальных весах

По API Hugging Face, присланному пользователем: это `lora.safetensors`,
687476088 байт, revision `328160f16bc4072cf2bb7ee162d77f3b9b5f786c`,
для базовой `black-forest-labs/FLUX.1-dev`. В карточке LoRA указана OpenRAIL-M;
база имеет отдельную Non-Commercial License, проверенную в официальном репозитории BFL.

Код `flux_lora`, загрузчик, расширение GPU-образа, проба NF4/PEFT и инструкция
возврата к Klein подготовлены. Фактический импорт GPU-зависимостей, загрузка
адаптера, потребление памяти, скорость и качество этого режима ещё не подтверждены.
Пользователю требуется помощь с доступом к FLUX.1-dev. Токен в чат не запрашивается.

Следующие обязательные проверки перечислены в `heartsync-ru.md`: доступ аккаунта,
NF4 + LoRA CUDA probe, загрузка базы и адаптера, готовность нового воркера,
оба smoke с `--expect-engine flux_lora`, просмотр изображений и возврат при сбое.
Успешные CPU-тесты не заменяют эти испытания.
